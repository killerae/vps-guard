# 测试状态

版本：0.3.0。

## 已在当前 Windows 开发环境验证

- Python 源码编译、命令行帮助。
- 单元测试使用临时文件系统及模拟命令执行器，覆盖只读检查、参数拒绝、文件恢复、陈旧恢复保护、SSH 新连接门槛、计时器期限、多队列规划、缓冲区预算和凭据文件解析。
- Git Bash 的安装脚本与启动器语法检查。
- JSON 片段结构、发布清单与 ZIP 完整性。
- 个人预设无配置问答、指定公钥、免密 sudo 语法和可用性检查、APT 非交互选项、Swap 保留。
- 防火墙监听识别、未知业务／Docker／自定义 IPv4／IPv6／nftables 规则保留、网络不支持时跳过并报告。
- 个人预设两次新连接的完整模拟流程、失败报告、旧事务升级保护。
- 向导选择、统一恢复、单计时器、新连接时间／公钥核对、中断续跑、确认前备份凭据不落盘。
- 两次独立连接推动完整向导的模拟流程。
- bootstrap 固定清单、逐文件校验、路径穿越／符号链接／重复条目拒绝、体积限制和未认证文件不解压。

这些检查不会修改开发电脑的 SSH、防火墙、网络、账号或系统服务。

## 需要在 Linux 测试机完成

- Debian／Ubuntu 的具体版本、systemd 与 Python 兼容性。
- 初始 root → ops 密钥登录及 sudo 的完整迁移。
- 正常确认、故意不确认触发恢复、配置错误触发恢复。
- SSH Match、socket activation、已有自定义端口。
- UFW／Fail2ban 的实际 IPv4、IPv6 与封禁路径。
- BBR 模块、fq／mq、真实队列参数恢复与重启持久化。
- Swap 的文件系统支持、容量与安全停用。
- 安全更新任务、日志容量、通知送达。
- restic 目的地连接、调度、备份和文件／业务恢复。
- Netcatty 实际版本的导入、当前终端执行与新连接确认。
- 所有已应用阶段的二次执行与重启后验收。

GitHub Actions 使用 Linux Python 3.10／3.12 运行单元测试、清单和语法检查。公开仓库还执行无 Token 的固定提交下载校验（download-only），不安装或修改 CI 主机。是否通过以对应提交的 Actions 结果为准。

bootstrap 内记录固定的工具包提交及清单哈希。发布时先提交并测试运行时，再更新入口绑定该提交，避免哈希循环。具体绑定以 bootstrap.sh 为准。
